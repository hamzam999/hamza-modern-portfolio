# Portrait slot

Drop the owner's own photo here as `hamza.jpg` (or `.png`, `.webp`), at least 800 px wide, portrait or square
(it is cropped to 4:5 around the subject). `npm run media` turns it into a duotone (ink to paper) print at 480 and 800 px
in `public/profile/` and the Origin level shows it in the framed slot with a stamp overlay. Without the file the page
shows the hamza stamp placeholder. Do not use stock photos.
