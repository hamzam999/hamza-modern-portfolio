# Unverified screenshots

These captures show third-party interfaces (Safe{Wallet}, an OpenSea-like homepage), not confirmed owner work.
The owner must confirm rights before any of them is used. Until then they are not read by `npm run media`,
so the projects use PosterFallback and no image appears in covers, heroes, sitemap, JSON-LD, OG or llms files.
To restore one: confirm rights, then move it back to `media-src/projects/<slug>/screenshot.png`.
