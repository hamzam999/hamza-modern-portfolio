# ERPNext for Manufacturing

- Category: Full-stack and Product
- Status: private (not linked)
- Year: 2026
- Engagement: Client; in daily use at the factory
- Role: Sole developer. Mapped the client’s manual production workflow, then built a custom frontend app to replace it using native backend APIs and functions.
- Stack: ERPNext, Frappe, Next.js, Docker, GitHub Actions
- Link: none
- Page: https://www.erhamza.tech/projects/erpnext-manufacturing

A custom app built on ERPNext that replaced a factory’s manual production tracking by reproducing the existing workflow. It records what goes into each product, the work orders and how much each worker made, then creates the weekly payment vouchers for labourers. It is in daily use at the factory.

## Highlights

- Custom doctypes and workflows for BOM, work orders and production tracking
- Payment voucher generation for weekly completed quantities for labourers
- Docker-based ERPNext environment with GitHub Actions CI/CD
