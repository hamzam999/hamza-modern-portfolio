# NFT Marketplace

- Category: Web3
- Status: shut down (no longer online)
- Year: 2024
- Engagement: Employer: ITH Technologies
- Role: Main frontend developer, leading the blockchain integration of the smart contracts. The contracts were written by others.
- Stack: React, Paymaster, Solana Web3, ERC-721, ERC-1155
- Link: none
- Page: https://www.erhamza.tech/projects/nft-marketplace

A marketplace, similar to OpenSea, where creators make, buy and sell digital collectibles. It used ERC-721 and ERC-1155 contracts on Base, with Sui and Solana supported alongside. It had minting and trading flows, lazy minting (listing an item before it is minted), auctions and fixed-price sales, and creator dashboards, and the platform covered the network fee when creators minted. I was the main frontend developer and led the blockchain integration of the smart contracts, which were written by others. The project has since shut down.

## Highlights

- Marketplace supporting ERC-721 and ERC-1155 with minting and trading flows
- Lazy minting, auctions and creator dashboards
