# Unified Trading CRM

- Category: Full-stack and Product; Web3
- Status: private (not linked)
- Year: 2025
- Engagement: Employer: ITH Technologies
- Role: Developer in a team. Merged multiple trading platforms into one Next.js CRM with multi-tenant access control, reducing load times by 35%.
- Stack: Angular, Next.js
- Link: none
- Page: https://erhamza.tech/projects/unified-trading-crm

Several separate trading tools built on Angular were merged into one Next.js CRM, with multi-tenant access control so each client account sees only what it should. Load times dropped by 35%, and performance improved by 30–50% with SSR/SSG and code splitting.

## Results

- Reducing load times by 35% (owner-reported)
- Improved performance by 30-50% using SSR/SSG and code splitting (owner-reported)
