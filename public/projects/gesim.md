The first MVP of GeSIM, a Web3 app for global eSIM mobile data. I built the web app in React, mainly the blockchain integration: wallet connection, purchases, transactions and their status. I also worked on blockchain integration in the React Native mobile app. The web app is live; the mobile app is not published.

## Highlights

- Web MVP live at gesim.xyz; the React Native mobile app is not published

## Product scope (facts about the product, not the owner's work)

- Global eSIM mobile data across 190+ countries without traditional carrier ID requirements
- Built-in VPN, virtual numbers, global spending cards, and access to global and tokenized markets
