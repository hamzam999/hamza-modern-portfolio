# BookEase

- Category: WordPress and Client
- Status: public repository
- Year: 2026
- Engagement: Client
- Role: Built for a client
- Stack: PHP 8, WordPress, object-oriented PHP, WordPress REST API
- Link: https://github.com/hamzam999/bookEase
- Page: https://erhamza.tech/projects/bookease

A booking plugin for WordPress sites. Hotels, restaurants and clinics let customers pick a free time slot, get confirmation emails, and cancel or reschedule from a link. Staff can export bookings to CSV. It is installable from GitHub: download it and install it.

By Mohammad Hamza: https://erhamza.tech/
